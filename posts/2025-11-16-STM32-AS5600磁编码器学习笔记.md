## 前言

本文基于**江协科技 STM32 基础教程**（I2C 通信原理见教程第十章），代码在江协科技开源教程代码的基础上编写，AS5600 部分参考了无刷直流电机商家提供的例程。

## 一、编码器实物

AS5600 是一款**非接触式磁编码器**，核心依靠霍尔效应传感器检测旋转角度，常用于电机旋转位置反馈。

使用关键要求：

- 需在电机旋转轴上安装**径向磁铁**；
- 磁铁要贴近 AS5600 芯片，两者间隔控制在 **1mm 以内**（本文用的是开源款磁性编码器）。

> 📷 配图：AS5600 磁编码器实物（图片放到 `images/as5600/` 后再替换本行）

## 二、IIC 通信地址

AS5600 的 I2C 从机地址为 `0x36`，左移 1 位（含读写位）后是 `0x6C`，对应代码里的宏 `AS5600_ADDRESS`。

| 项目 | 地址 | 宏定义 |
| --- | --- | --- |
| I2C 从机地址 | `0x36 << 1` = `0x6C` | `AS5600_ADDRESS` |
| RAW ANGLE 高 8 位 | `0x0E` | `AS5600_ANGLE_H` |
| RAW ANGLE 低 8 位 | `0x0F` | `AS5600_ANGLE_L` |

按数据手册，主要用到 OUTPUT 区里 RAW ANGLE 的两个寄存器：高字节 `0x0E`、低字节 `0x0F`。拼起来是一个 12 位的原始角度值（0–4095），线性对应 0–360°。

> 📷 配图：数据手册里的寄存器地址表（图片放到 `images/as5600/`）

## 三、硬件接线

主控为 **STM32F103C8T6**。软件部分基于江协科技的 MyI2C 驱动编写，硬件 I2C 的接法也一样。

| 模块 | 接线 |
| --- | --- |
| 0.96 寸 OLED 屏 | SCL → PB8，SDA → PB9 |
| AS5600 磁编码器 | 3.3V → 3.3V，GND → GND，SCL → PB10，SDA → PB11 |
| USB 转串口模块（可选）| RXD → PA9，TXD → PA10 |

注意：AS5600 走的是 **I2C2**（PB10 / PB11），和 OLED 用的那组 I2C（PB8 / PB9）是分开的。

- **串口测试**：打印原始值与换算后的角度

## 五、使用源码（硬件 I2C 版）

```c
#include "stm32f10x.h"                  // Device header

//宏定义
#define AS5600_ADDRESS		0x6C		//AS5600的I2C从机地址
#define AS5600_ANGLE_H		0x0E
#define AS5600_ANGLE_L		0x0F

/**
  * 函    数：AS5600等待事件
  * 参    数：同I2C_CheckEven
  * 返 回 值：无
  */
void AS5600_WaitEvent(I2C_TypeDef* I2Cx, uint32_t I2C_EVENT)
{
	uint32_t Timeout;
	Timeout = 10000;									//给定超时计数时间
	while (I2C_CheckEvent(I2Cx, I2C_EVENT) != SUCCESS)	//循环等待指定事件
	{
		Timeout --;										//等待时，计数值自减
		if (Timeout == 0)								//自减到0后，等待超时
		{
			/*超时的错误处理代码，可以添加到此处*/
			break;										//跳出等待，不等了
		}
	}
}

/**
  * 函    数：AS5600读寄存器
  * 参    数：RegAddress 寄存器地址，范围：参考AS5600手册的寄存器描述
  * 返 回 值：读取寄存器的数据，范围：0x00~0xFF
  */
uint8_t AS5600_ReadReg(uint8_t RegAddress)
{
	uint8_t Data;

	I2C_GenerateSTART(I2C2, ENABLE);										//硬件I2C生成起始条件
	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_MODE_SELECT);

	I2C_Send7bitAddress(I2C2, AS5600_ADDRESS, I2C_Direction_Transmitter);	//硬件I2C发送从机地址，方向为发送
	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_TRANSMITTER_MODE_SELECTED);	//等待EV6

	I2C_SendData(I2C2, RegAddress);											//硬件I2C发送寄存器地址
	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_BYTE_TRANSMITTED);				//等待EV8_2

	I2C_GenerateSTART(I2C2, ENABLE);										//硬件I2C生成重复起始条件
	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_MODE_SELECT);					//等待EV5

	I2C_Send7bitAddress(I2C2, AS5600_ADDRESS, I2C_Direction_Receiver);		//硬件I2C发送从机地址，方向为接收
	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_RECEIVER_MODE_SELECTED);		//等待EV6

	I2C_AcknowledgeConfig(I2C2, DISABLE);									//在接收最后一个字节之前提前将应答失能
	I2C_GenerateSTOP(I2C2, ENABLE);											//在接收最后一个字节之前提前申请停止条件

	AS5600_WaitEvent(I2C2, I2C_EVENT_MASTER_BYTE_RECEIVED);				//等待EV7
	Data = I2C_ReceiveData(I2C2);											//接收数据寄存器

	I2C_AcknowledgeConfig(I2C2, ENABLE);									//将应答恢复为使能，为了不影响后续可能产生的读取多字节操作

	return Data;

}

/**
  * 函    数：AS5600初始化
  * 参    数：无
  * 返 回 值：无
  */
void AS5600_Init(void)
{
		/*开启时钟*/
	RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C2, ENABLE);		//开启I2C2的时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);		//开启GPIOB的时钟

	/*GPIO初始化*/
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_OD;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_10 | GPIO_Pin_11;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);					//将PB10和PB11引脚初始化为复用开漏输出

	/*I2C初始化*/
	I2C_InitTypeDef I2C_InitStructure;						//定义结构体变量
	I2C_InitStructure.I2C_Mode = I2C_Mode_I2C;				//模式，选择为I2C模式
	I2C_InitStructure.I2C_ClockSpeed = 50000;				//时钟速度，选择为50KHz
	I2C_InitStructure.I2C_DutyCycle = I2C_DutyCycle_2;		//时钟占空比，选择Tlow/Thigh = 2
	I2C_InitStructure.I2C_Ack = I2C_Ack_Enable;				//应答，选择使能
	I2C_InitStructure.I2C_AcknowledgedAddress = I2C_AcknowledgedAddress_7bit;	//应答地址，选择7位，从机模式下才有效
	I2C_InitStructure.I2C_OwnAddress1 = 0x00;				//自身地址，从机模式下才有效
	I2C_Init(I2C2, &I2C_InitStructure);						//将结构体变量交给I2C_Init，配置I2C2

	/*I2C使能*/
	I2C_Cmd(I2C2, ENABLE);									//使能I2C2，开始运行

}

/**
  * 函    数：AS5600获取数据
  * 参    数：AS5600_ANGLE 原始 12 位角度，angle_val 整数角度，angle_valL 角度余数
  * 返 回 值：无
  */
void AS5600_GetData(int16_t *AS5600_ANGLE,int16_t *angle_val,uint16_t *angle_valL)
{
	uint8_t DataH, DataL;								//定义数据高8位和低8位的变量

	DataH = AS5600_ReadReg(AS5600_ANGLE_H);		//读取角度高8位数据
	DataL = AS5600_ReadReg(AS5600_ANGLE_L);		//读取角度低8位数据
	*AS5600_ANGLE = (DataH << 8) | DataL;						//数据拼接，通过输出参数返回
	*angle_val = 360*(*AS5600_ANGLE)/4096;
	*angle_valL =360*(*AS5600_ANGLE)%4096;
}
```
