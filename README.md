- 一篇一个文件，放在 `posts/`，命名 `YYYY-MM-DD-主题.md`
- 图片放 `images/<文章名>/`，正文里用相对路径引用：`![](../images/文章名/图片.png)`
  （**不要直接引用 CSDN / 知乎的图片地址**，那些站有防盗链，在这里会裂图）

- 写完记得更新上面的文章表
